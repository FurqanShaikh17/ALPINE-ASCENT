# Alpine Ascents - University Semester Project

Alpine Ascents is a web portal that I developed for my University Semester Project. The main goal of this project is to provide a reliable platform for mountaineering enthusiasts to find real and accurate information about various mountain peaks and trekking routes.

## Project Details
- **Real Information:** The website contains authentic data about peaks like K2, Kangchenjunga, and Lhotse, including their actual geographical locations.
- **UI/UX Design:** I have used professional templates as a base and heavily customized them to create a unique look that fits the mountaineering theme.
- **Responsiveness:** The layout is fully responsive, meaning it works smoothly on mobile phones, tablets, and desktop screens.

## Technical Tools Used
- **Frontend:** Built using HTML5, CSS3, and JavaScript.
- **Frameworks & Libraries:** I integrated Bootstrap 5 for the grid system and used jQuery along with some other UI libraries to handle interactive elements.
- **Version Control:** I used Git and GitHub to manage the code and track different versions of the project.

## Project Purpose
This project was built to show how we can combine custom coding with existing professional tools to create a functional and real-world web application. It covers everything from layout design to the integration of third-party libraries.
